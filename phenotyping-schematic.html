Constrained conformal phenotyping: turning per-cell marker intensities into typed cells with a distribution-free rule and a biological feasible set

Mirage's PHENOTYPE step does not threshold markers. Each marker call is a two-sided, rank-based conformal test evaluated inside a local-density stratum; a compile-time feasible set of biologically allowed marker combinations then resolves each cell to one of five outcomes, and Conformal Risk Control tunes the single decision level so audited co-expression stays under a target rate. The design lives in bin/utils/phenotyping/ and runs once per patient from a frozen, hash-stamped model_config.json.

a

c

The per-cell pipeline — ①→⑦ with the actual math

Every cell, every marker. si is the cell's intensity for the marker; calibration sets are that marker's negative / positive reference cells within the cell's own density bin.

1
DENSITY & BINS density.py · compute_density → mondrian_bins
Local crowding per cell, then quantile-binned into density strata so a marker is only ranked against neighbours in comparable tissue context (Mondrian conformal — the mechanism against crowding-driven spillover).
radius = c·mediani(NNi) ,   ρi = #{ j≠i : ‖xi−xj‖ ≤ radius }
2
CALIBRATE per marker calibration.py · degrade guard D5
Select neg/pos reference cells from the source panel b assigned (GMM crossover on the marker or its partner/antecedent), split by density bin. If a bin holds < min_calibration (default 50) of either class, collapse to one global bin; if still short, mark the marker degraded (see L3).
3
CONFORMAL SCORES conformal.py · two one-sided rank p-values
Rank the cell against each calibration set. Small pneg ⇒ brighter than the negatives ⇒ reads positive; small ppos ⇒ dimmer than the positives ⇒ reads negative.
pneg = 1 + #{ c ∈ neg : c ≥ si }|neg| + 1 , ppos = 1 + #{ c ∈ pos : c ≤ si }|pos| + 1
4
RESOLVE SIGN @ α conformal.resolve_sign · two-sided at level α
Keep neg in the set iff pneg > α; keep pos iff ppos > α. Four states, not two:
pos 1 ppos>α, pneg≤α neg 0 pneg>α, ppos≤α free · both >α (undetermined) contra × both ≤α (impossible → artefact)
5
CLASSIFY vs F classify.py · sign sub-cube ∩ feasible set
Intersect the resolved sign sub-cube with F and count distinct phenotype names. One name → committed; the Unclassified singleton → Unclassified; >1 → Ambiguous; empty-with-explanation → Conflict; empty-or-contra → Artefact (panel e).
6
CRC α-TUNING crc.py · wraps ①–⑤ across an α-grid
Risk grows with α (looser thresholds commit more cells, so audited co-positivity can only rise). Pick the largest α whose Hoeffding upper bound on excess co-positivity still clears the target — least abstention that keeps the guarantee.
R(α) = meanpairs max(0, obsab − nominalab) ,  UCB = R + √ln(1/δ)2n α* = max{ α : UCB(α) ≤ αtarget }
7
SOFT SCORES + STATES scoring.py · softmax over surviving patterns
Turn the surviving candidate patterns into a probability over phenotype names (exported as pheno_score:<Name>), so even an Ambiguous cell carries a distribution downstream. State markers (Ki67) reuse the same p-values but collapse to +1/−1/0 and are reported, never used to decide identity.
score(pat) = Σk ℓk − Σenforce λ·1[a=1∧b=1] ,  ℓk = log(1 − p·)  (0 if free)

Five outcomes — and why the two failures differ

The value of counting distinct names against F is that "no answer" is split into a diagnosable Conflict and an unexplained Artefact, instead of a single silent "Unknown".

<Phenotype>
committed · type 0
Exactly one distinct name survives ∩ F. A free marker can be absorbed by F into a confident singleton.
Unclassified
type 0
The single surviving name is literally Unclassified — a feasible but unnamed corner of the cube.
Ambiguous
type 0
>1 distinct name survives. Not discarded — pheno_score:* carries the full distribution downstream.
Conflict
type 1 · has id
Empty ∩ F, explained by a confident never/requires violation → the exact constraint id is recorded.
Artefact
type 2
Empty ∩ F with no confident explanation, or any marker resolved contra — segmentation/registration junk.
f

Limitations & failure modes — where the guarantee thins

The method is well-engineered, but its statistical promises are conditional. Each item below was confirmed by running the code, not inferred. Evidence lines are verbatim program output.

L1 The "distribution-free" claim leaks at the reference step design

Markers with no structural anchor (here CD4, CD8, and every positive fallback) draw both calibration sets from the same marker's own GMM crossover — a two-Gaussian threshold. Conformal ranking is only exchangeability-valid if calibration and test cells are drawn alike; selecting the extremes by a threshold breaks that hypothesis. The p-values are principled heuristics, not a coverage guarantee, and inherit every GMM error (tri-modal markers, batch shift, non-bimodal signal).

CD4 · CD8 · Ki67 → neg={gmm}, pos={gmm} (all thr ≈ 3.5)

L2 CRC risk control is silently off for simple panels silent

A single rare pair is two-coloured entirely into enforce, leaving audit empty, so crc_ran=False and α stays pinned at the target with no risk control — the headline "conformal risk control" does nothing unless the panel has enough overlapping rare pairs. Only a line in phenotype_qc.json reveals it.

1 rare pair → audit=[] CRC_runs=False 2 rare pairs → audit=[[CD8,GZMB]] CRC_runs=True

L3 Density stratification collapses exactly when it's needed silent

With min_calibration=50 and up to 5 bins, any marker whose positive population is modest (160 cells ≈ 32/bin < 50) fails the per-bin test and silently reverts to one global bin — the Mondrian anti-spillover mechanism turns off precisely for rarer cell types. Rarer still (< 50 positives total) → the marker degrades to free everywhere and drops out of classification.

5 bins requested · 159 positives → bins used: 1 [0]

L4 A panel/quant key typo degrades a marker, never errors footgun

The runtime looks up "marker: Compartment: Statistic". If the panel says Mean but quantification wrote Median (or a compartment differs), the column isn't found, the marker is filled with zeros and marked degraded → free everywhere. The run "succeeds" with a quietly missing marker behind one stderr [WARN].

panel wants 'CD8: Cytoplasm: Mean' quant has 'CD8: Cytoplasm: Median' → values=[0,0,0] degraded=True (no exception)

L5 One global α for all markers design

CRC selects a single α applied to every marker and phenotype. A clean bimodal lineage marker and a noisy, dim one are held to identical stringency; there is no per-marker or per-phenotype adaptivity, so a single weak channel can drag many cells into free/Ambiguous at the α the audited pairs happen to permit.

L6 Homogeneous-density assumption & per-cell cost scaling

Density uses a single global radius (median nearest-neighbour distance), so a slide mixing dense lymphoid aggregates with sparse stroma is mis-binned at both ends. Separately, conformal scoring is a per-cell rank against each calibration set (≈ O(n·|cal|) in Python loops) — fine at test scale, a watch-item at 10⁵–10⁶ cells per slide.

Supplementary Figure S2. Constrained conformal phenotyping in Mirage. (a) A data-free compile stage turns panel.yaml into a frozen, hash-stamped model_config.json; a runtime stage classifies each patient's cells against it. (b) The compiler enumerates every lineage sign vector, deletes constraint violations, and names the survivors by most-specific inherited signature to form the feasible set F; rare pairs are two-coloured into a soft enforce penalty and a risk-controlled audit set, and each marker's calibration source is resolved symbolically. (c) Per cell and marker, local density defines a stratum, two one-sided rank-based conformal p-values are computed within it, a two-sided test at level α resolves a four-valued sign, the sign sub-cube is intersected with F, Conformal Risk Control tunes α to bound audited co-positivity, and a softmax over surviving patterns yields exported per-name scores. (d) A verified end-to-end trace of one CD8 T cell, every number emitted by the real code. (e) The five-outcome taxonomy separates explained Conflicts from unexplained Artefacts. (f) Six confirmed limitations where the statistical guarantee is conditional on panel topology, calibration adequacy, or input hygiene. Worked-example and limitation values were produced by executing bin/utils/phenotyping/ on a controlled synthetic cohort compiled from tests/testdata/panel_min.yaml; feasible-set and constraint values are the compiler's own output.
