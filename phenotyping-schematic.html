Supplementary Figure S2 · companion to S1 · rev. 2 — weighted conformal calibration

Constrained conformal phenotyping: turning per-cell marker intensities into typed cells with a distribution-free rule and a biological feasible set

Mirage's PHENOTYPE step does not threshold markers. Each marker call is a two-sided, rank-based conformal test evaluated inside a local-density stratum; a compile-time feasible set of biologically allowed marker combinations then resolves each cell to one of five outcomes, and Conformal Risk Control tunes the single decision level so audited co-expression stays under a target rate. This revision replaces hard-threshold calibration with responsibility-weighted conformal scoring, adds a requires_neg structural anchor, and reports a Kolmogorov–Smirnov calibration self-check — closing the exchangeability leak flagged in rev. 1. Code lives on branch feat/conformal-calibration (bin/utils/phenotyping/).

a

Primer — conformal prediction in one page

The whole method rests on one idea: turn a raw number into a calibrated statement with an error guarantee, without assuming any distribution. Read this first; everything after is this idea, specialised.

The three ingredients

  1. A calibration set — known reference examples of a class (here: cells that are reference-negative, or reference-positive, for one marker).
  2. A nonconformity score — one number saying how "unusual" a point is. Here it is simply the marker intensity si.
  3. A rank p-value — where the new point falls among the calibration scores:
p = 1 + #{ calibration scores at least as extreme as q }|calibration| + 1
Concrete: a cell's CD8 = 6.2. Of 99 reference-negative cells, 0 are that bright, so pneg = (1+0)/(99+1) = 0.01. "Being a negative would be a 1-in-100 event" → we reject "negative" → the cell reads positive.

The one guarantee & the one catch

Guarantee (marginal coverage). If the new point and the calibration set are exchangeable (drawn alike), the p-value is ~Uniform(0,1), so:

P( p ≤ α ) ≤ α

Thresholding p at α therefore controls the false-call rate at α — distribution-free. Test both labels and keep each whose p > α: the result is a prediction set, not a forced 0/1.

The catch — exchangeability. The guarantee dies the instant you build the calibration set using the test point's own value (e.g. "negatives = everything below this threshold"). That was rev. 1's bug; rev. 2's weighting is the fix (panel f).

Why requires_neg matters: the contrapositive of CD8 → CD3 is ¬CD3 → ¬CD8. So CD3-negative cells form CD8's negative reference on a different channel — CD8 is no longer thresholded against its own distribution, which is exactly what conformal validity requires.

d

The per-cell pipeline — ①→⑦ with the actual math

Every cell, every marker. si is the cell's intensity; wj is reference cell j's soft membership weight in the calibration class (rev. 2).

1
DENSITY & BINS density.py · compute_density → mondrian_bins
Local crowding per cell, then quantile-binned into density strata (Mondrian conformal), so a marker is only ranked against neighbours in comparable tissue context — the mechanism against crowding-driven spillover.
radius = c·mediani(NNi) ,   ρi = #{ j≠i : ‖xi−xj‖ ≤ radius }
2
WEIGHTED CALIBRATE rev. 2 calibration.py · GMM posteriors, not thresholds
Give every cell a soft membership weight in the neg / pos reference class — the two-component-GMM posterior on whichever channel the source (partner / requires / self) names. No cell is dropped; a confident positive simply gets wneg≈0. Adequacy is the effective count Σw ≥ min_calibration; below that, collapse bins, then degrade.
wpos(s) = P(high mode | s) ,  wneg = 1 − wpos  (or a partner/consequent channel's posterior)
3
WEIGHTED CONFORMAL SCORES rev. 2 conformal.py · weighted empirical tail
Rank the cell against the whole reference population, each cell weighted by its membership. Small pneg ⇒ brighter than the (weighted) negatives ⇒ positive; small ppos ⇒ dimmer than the positives ⇒ negative.
pneg(q) = Σj wj · 1[ sj ≥ q ]Σj wj , ppos(q) = Σj wj · 1[ sj ≤ q ]Σj wj
·
CALIBRATION SELF-CHECK rev. 2 conformal.ks_uniform → phenotype_qc.json
On genuinely-reference cells the p-values should be ~Uniform(0,1) if calibration is valid. The KS distance to uniform is reported per marker/direction: near 0 = well calibrated; a large value flags the old truncation pathology (p-values piled at 0/1). This is a label-free audit that the exchangeability fix is actually working.
KS = supt | F̂(t) − t |  over p-values of the w>0.9 reference cells
4
RESOLVE SIGN @ α conformal.resolve_sign · two-sided prediction set
Keep neg in the set iff pneg > α; keep pos iff ppos > α. Four states, not two:
pos 1 ppos>α, pneg≤α neg 0 pneg>α, ppos≤α free · both >α (undetermined) contra × both ≤α (impossible → artefact)
5
CLASSIFY vs F classify.py · sign sub-cube ∩ feasible set
Intersect the resolved sign sub-cube with F and count distinct phenotype names. One name → committed; the Unclassified singleton → Unclassified; >1 → Ambiguous; empty-with-explanation → Conflict; empty-or-contra → Artefact (panel g).
6
CRC α-TUNING crc.py · wraps ①–⑤ across an α-grid
Risk grows with α (looser thresholds commit more cells, so audited co-positivity can only rise). Pick the largest α whose Hoeffding upper bound on excess co-positivity still clears the target — least abstention that keeps the guarantee.
R(α) = meanpairs max(0, obsab − nominalab) ,  UCB = R + √ln(1/δ)2n α* = max{ α : UCB(α) ≤ αtarget }
7
SOFT SCORES + STATES scoring.py · softmax over surviving patterns
Turn the surviving candidate patterns into a probability over phenotype names (exported as pheno_score:<Name>), so even an Ambiguous cell carries a distribution. State markers (Ki67) reuse the same p-values but collapse to +1/−1/0 and are reported, never used to decide identity.
score(pat) = Σk ℓk − Σenforce λ·1[a=1∧b=1] ,  ℓk = log(1 − p·)  (0 if free)

step ⑦ · why the score is ≈ 0 here

Every marker is confidently resolved, so each ℓk = log(1 − p) ≈ log(1) ≈ 0 and the log-score ≈ 0 for the sole candidate → softmax = 1.0. The score machinery earns its keep on Ambiguous cells, where two candidate patterns survive and the log-likelihood difference splits the probability mass between competing phenotype names.

f

This revision — closing the exchangeability leak

Rev. 1 (panel h, L1) computed p-values against a calibration set truncated at the GMM crossover — the reference was selected using the very quantity being tested, breaking conformal validity. Rev. 2 keeps every cell and weights it.

✕ rev. 1 — hard-threshold calibration

Negatives = cells below the GMM threshold; the p-value ranked against that truncated subset. The reference contained and was defined by the score under test → p-values piled up near 0 and 1, not Uniform.

neg = { j : s_j < thr } p_neg = (1 + #{neg ≥ q}) / (|neg| + 1)

✓ rev. 2 — responsibility-weighted

All cells kept; each weighted by its GMM soft membership w = P(class | s). A confident positive has wneg≈0, so it neither pollutes nor truncates the negative reference. Exchangeability is restored in expectation, and the KS self-check confirms it.

w_neg = 1 − P(high | s) (per cell, ∈[0,1]) p_neg = Σ w·1[s ≥ q] / Σ w

Three supporting changes ship with the weighting: (1) a requires_neg structural anchor (panel c) so more markers calibrate off a different channel; (2) a degrade guard on effective sample size Σw rather than a raw count; (3) the ks_uniform diagnostic in phenotype_qc.json. 333 tests green on feat/conformal-calibration; not yet merged to main.

g

Five outcomes — and why the two failures differ

The value of counting distinct names against F is that "no answer" is split into a diagnosable Conflict and an unexplained Artefact, instead of a single silent "Unknown".

<Phenotype>
committed · type 0
Exactly one distinct name survives ∩ F. A free marker can be absorbed by F into a confident singleton.
Unclassified
type 0
The single surviving name is literally Unclassified — a feasible but unnamed corner of the cube.
Ambiguous
type 0
>1 distinct name survives. Not discarded — pheno_score:* carries the full distribution downstream.
Conflict
type 1 · has id
Empty ∩ F, explained by a confident never/requires violation → the exact constraint id is recorded.
Artefact
type 2
Empty ∩ F with no confident explanation, or any marker resolved contra — segmentation/registration junk.
h

Limitations & failure modes — where the guarantee thins

Each item was confirmed by running the code. Rev. 2 resolves L1 and softens L3; the rest remain open. Evidence lines are verbatim program output.

L1 Exchangeability leak at the reference step resolved · rev. 2

The "distribution-free" claim used to leak because calibration sets were hard-cut at the GMM crossover (panel f). Fixed by responsibility-weighting + the requires_neg anchor. The KS self-check now certifies calibration per run — reference-cell p-values are ~Uniform, so the guarantee holds in expectation.

KS-to-uniform (all markers): 0.003 – 0.013 → valid

L2 CRC risk control is silently off for simple panels open · silent

A single rare pair is two-coloured entirely into enforce, leaving audit empty, so crc_ran=False and α stays pinned at target with no risk control — the "conformal risk control" does nothing unless the panel has enough overlapping rare pairs. Only a line in phenotype_qc.json reveals it. Unchanged in rev. 2.

1 rare pair → audit=[] CRC_runs=False 2 rare pairs → audit=[[CD8,GZMB]] CRC_runs=True

L3 Density stratification collapse softened · rev. 2

Adequacy is now measured by effective mass Σw, not a raw count, so partially-confident cells still contribute and fewer markers collapse to a single global bin. The failure mode is milder but not gone: a genuinely rare positive population (small Σw) still collapses, and a marker with too little effective mass still degrades to free.

L4 A panel/quant key typo degrades a marker, never errors open · footgun

The runtime looks up "marker: Compartment: Statistic". If the panel says Mean but quantification wrote Median, the column isn't found, the marker is zero-filled and marked degraded → free everywhere. The run "succeeds" with a quietly missing marker behind one stderr [WARN]. Unchanged in rev. 2.

panel wants 'CD8: Cytoplasm: Mean' quant has 'CD8: Cytoplasm: Median' → values=[0,0,0] degraded=True (no exception)

L5 One global α, and calibration still leans on the GMM open · design

CRC selects a single α for every marker and phenotype — no per-marker adaptivity. And while weighting removes the truncation, the membership weights are still a two-component-GMM posterior: a genuinely tri-modal or non-Gaussian marker gives biased weights (the KS check will flag it, but nothing auto-corrects).

L6 Homogeneous-density assumption & per-cell cost open · scaling

Density uses a single global radius (median nearest-neighbour distance), so a slide mixing dense lymphoid aggregates with sparse stroma is mis-binned at both ends. The weighted tail is a vectorised cumulative-sum (an improvement over the rev. 1 scalar loop), but still ≈O(n log n) per marker per bin — a watch-item at 10⁵–10⁶ cells per slide.
